# Edge Hill Drinks Vending Machine

## Overview
This browser-based prototype of a drinks machine was created for CIS2722 Coursework Task 1. It used HTML / JS / CSS in order to provide a responsive GUI experience while checking boxes for UI/UX, requirements, and OOP development.

## Features
- Allows a user to view drinks and select them by ID through text input.
- Simulates cash and card payment through seperate components and modals.
- Loyalty ID validation that applies 10% discount upon use.
- Admin controls for restocking, viewing cash inventory (and collecting it) and transaction logs.

## Limitations
- All transactions are **completely simulated**, displaying primarily the User's logical flow through the system.
- There is **no proper security** for Admin panel or bank details implemented, all similar actions are **purely simulation**.
